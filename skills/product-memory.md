# Product memory check

Use before changing a feature or accepting a product behavior change.

1. Identify the affected feature and retrieve active product decisions, linked change history, known constraints and prior incidents. Record each source ID and version.
2. Compare the proposed behavior with the approved behavior. Mark missing or conflicting context as unresolved; request a product decision when the change alters approved behavior.
3. Link any approved replacement to the superseded decision. Keep both decisions and their reasons discoverable. Complete only when the change cites the active decision set or is waiting on an explicit product decision.
