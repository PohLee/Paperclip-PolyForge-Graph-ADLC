# Review and handoff

Use for important design, plan and code submissions.

1. Pin the artifact ID and version. Run a self review, record findings by severity, fixes and evidence. Repeat until no P0/P1 remains or round five has completed.
2. Submit the artifact and all rounds to the named supervisor, including unresolved P0/P1. Round five triggers handoff; it never creates approval.
3. As supervisor, start from the isolated review packet: pinned requirement and accepted architecture constraints, candidate identity and diff or artifact reference, and actual test results including failures and skips. Inspect the artifact directly using a different execution identity from the author. Record findings with severity and location, then acceptance or rework with reasons, known risks and required retests. Compare author self-review after the initial independent disposition. Complete when the decision record is durable and the next graph state reflects it.
