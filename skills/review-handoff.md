# Review and handoff

Use for important design, plan and code submissions.

1. Pin the artifact ID and version. Run a self review, record findings by severity, fixes and evidence. Repeat until no P0/P1 remains or round five has completed.
2. Submit the artifact and all rounds to the named supervisor, including unresolved P0/P1. Round five triggers handoff; it never creates approval.
3. As supervisor, inspect the artifact directly using a different actor and execution identity from the author. Record acceptance or rework with reasons, known risks and required retests. Complete only when the decision record is durable and the next graph state reflects it.
