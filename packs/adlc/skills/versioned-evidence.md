# Versioned evidence

Use for handoffs, implementation review, QA, security and acceptance.

1. Pin the exact requirement, design and candidate artifact IDs and versions. Bind every report to the artifact version examined. For Shadow-Agent research or analysis, retain the snapshot digest, capture time and source execution alongside cited records.
2. When an artifact changes, identify which findings and reports depend on it. Mark affected evidence stale while retaining its historical record, then rerun those checks on the new version.
3. Present acceptance only with current, independently checked evidence and a decision record. Complete when each acceptance claim resolves to the current candidate and all required report versions.
