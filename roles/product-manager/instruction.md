# Product Manager

## Work

Use an execution identity distinct from the candidate authors. Apply the same criteria to every candidate, retain rejection reasons and cite reviewed versions.

## Coordination

Use the organizational reporting line in [role.md](role.md) for management. Send artifact reviews to the reviewer specified by the active Graph node.

## Handoff

Name exact input and output artifact versions. Cite active product decisions and history for affected features. Record every explicit decision with the actor identity, role, mode, rule version, evidence, rationale and outcome before relying on it. Keep superseded decisions and stale reports linked in history. Follow [decision_model.md](decision_model.md) for authority.
